# MolVision 20 批交付总结

## 已实现并验证

### 渲染与交互
- 透明双遍：背面→正面混合，半透明远侧不再被隐藏
- 描边/SSAO：默认关闭，可独立开启，弱/标准/强三档
- 核酸：骨架、卡通、Ribbon（椭圆截面/圆角端盖/渐变）、Ribbon+倒角碱基平面
- 网格双面渲染、背面法线翻转、连接棒球形封盖
- 2D ↔ 3D 选中联动、2D 原子编号
- 大蛋白自动 LOD（>3 万原子切 CA 骨架）

### 导入 / 导出
- 导入：SDF/MOL、PDB、mmCIF、CSV/TSV、MOL2、XYZ、XLSX、`.gz`
- CSV 列映射、编码探测、批量应用；PDB/mmCIF HETATM 拆分
- 导出：PNG（300 DPI/透明底/高分辨率）、2D SVG/PNG、批量 ZIP、PDF、剪贴板、WebM 转盘、GIF 转盘、项目 `.mvproj`

### 选择 / 标注
- 结构显示/隐藏、列表搜索、叠加、序列动画
- 蛋白 CID 选择并在原结构上橙色高亮
- 标签增删/拖拽/重命名，距离/角度/二面角，撤销/重做
- 标注 CSV 导出，测量条目点击定位

### UI / 交付
- 中英文界面、语言持久化；英文 UI E2E 无中文残留
- 明/暗主题、可拖动侧栏、全屏、帮助弹窗、快捷键
- 最近项目、会话自动保存/恢复
- 窗口状态记忆、单实例
- Linux AppImage、Windows x64 zip、CI 三平台配置

## 验证
- `npm test`：10 项通过
- `npm run test:e2e`：SDF/gz/MOL2/XYZ/XLSX、2D、描边、英文 UI
- AppImage：Worker 解析、CID 高亮、复制、PDF/GIF/WebM 路径
- Windows zip：未签名、未在 Windows 实机运行

## 已知限制
- 后处理描边/SSAO 是屏幕空间近似，非 HBAO/几何轮廓
- 透明是双遍混合，不是逐三角形深度排序
- Worker 完整解析覆盖 SDF/MOL2/XYZ；PDB/mmCIF/CSV 仍主线程
- 核酸卡通为 Mesh 近似，不是 PyMOL 级完整卡通
- macOS 未构建；Windows 未签名
