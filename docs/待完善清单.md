## P1：格式与科学表达

| 项目 | 现状 / 问题 | 建议 |
| --- | --- | --- |
| CSV 编码 | `file.text()` 按 UTF-8；GBK/GB18030 中文会乱码 | 增加编码选择（UTF-8/GBK）或自动探测 |
| Excel | 只支持 CSV/TSV | 可选 `.xlsx`（SheetJS），或明确不支持 |
| CSV 列映射 | 支持两种 schema；不能“应用到本次全部 CSV”；无表头支持有限 | 批量应用映射；记住多套模板；无表头偏移行 |
| CSV 键/键级 | 坐标表只按共价半径推断单键 | 支持 `bonds.csv` / `i,j,order`；金属/离子不推断 |
| CSV 错误清单 | 坏 SMILES 只汇总数量 | 导出逐行错误 CSV（行号、原文、原因） |
| SDF 属性 | 不显示分子式/分子量/自定义字段 | 读取 `> <...>` 属性，信息面板展示；导出 manifest 带属性 |
| SDF 多记录 | 坏记录跳过，无逐条错误 | 记录级错误列表；可选“只导入成功项” |
| PDB 配体/离子 | HETATM 过滤水后全部混成一个“配体”条目 | 按残基名拆分；可选水/离子/辅因子；配体单独选择 |
| PDB 多模型/altloc | 只显示第一个模型；altloc 未暴露 | 模型切换；altloc 选择；生物装配（可选） |
| mmCIF 配体 | 只做蛋白/整体，不提取 HETATM | 与 PDB 对齐 |
| 核酸 | 无卡通，球棍回退 | 至少糖-磷酸骨架/卡通；或明确标注“不支持” |
| 测量 | 只有距离；无角度/二面角；单位固定 Å | 增加角度/二面角；单位切换；测量列表点击定位/编辑 |
| 2D | 仅小分子；2D 与 3D 无联动；批量只有 SVG 没有 2D PNG | 2D 选中与 3D 高亮同步；批量补 2D PNG |
| 标签/测距样式 | 颜色/字号/线型固定 | 样式面板；按残基/元素配色 |
